# Where do I put files? (Pinokio-style)

Everything lives **inside the StudioNels folder you downloaded** — same idea as Pinokio apps.

```
local-film-studio/
├── models/      ← AI models (or download in-app)
├── loras/       ← drop LoRA .safetensors here
├── outputs/     ← generated images / video / audio
├── uploads/     ← your reference images & clips
├── projects/    ← saved studio projects
├── addons/
│   ├── plugins/ ← plugin JSON add-ons
│   └── skills/  ← skill JSON / Markdown for the agent
├── cache/       ← settings & job queue (leave alone)
├── backend/
├── frontend/
└── presets/
```

Open the **Info** tab in the app for the same map with live paths on your machine.
