# Studio workflow

1. **New project** — name it, pick a mode (Film, Short, Music video, Ad, Experiment).
2. **Profiles** — add characters and scenes (look, voice notes, locations).
3. **Agent** — describe the idea. The agent returns a shot list using your profiles.
4. **Shots / Storyboard** — edit wording, camera, duration, attached profiles.
5. **Generate** — queue shots (low-VRAM sequential by default).
6. **Sampling** — compare takes, pin favorites.
7. **Characters** — create missing look refs anytime.
8. **Director** — pin clips on the timeline, reorder, trim notes, export plan.
9. **Save** — everything lands in `~/.framewright/projects/`.
