# models/

Put **downloaded AI models** here (or let StudioNels download them for you from the **Models** tab).

Each model gets its own subfolder, named like the Hugging Face id with `/` → `__`:

```
models/
  Wan-AI__Wan2.1-T2V-1.3B-Diffusers/
  stabilityai__sdxl-turbo/
```

Do **not** put LoRAs here — use `loras/` instead.
